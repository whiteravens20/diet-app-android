# Answers of a running backend

Each file is what a running diet-app answered one call of this client: `config.json` from API
0.77.0, captured on 2026-10-16 from a fresh install, the others from API 0.19.0, captured on
2026-10-13 with test accounts that were deleted afterwards. Tokens and the sign-in
challenge are replaced by `<removed>`. The files are refreshed from a running backend and
never edited by hand: a test that needs another answer gets it captured.
